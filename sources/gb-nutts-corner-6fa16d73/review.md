# Nutts Corner historical main course

This draft follows the northern dip chicane, inward western notch, eastern straight and short southern return at the Dundrod Road venue. Geometry comes only from the pinned OpenStreetMap snapshot dated 2018-01-01, with exact versioned ways and shared node joins. The closed route has 61 source positions and measures 840.9 m.

The catalogue scalar is 939 m. The 98.1 m difference remains unresolved and is disclosed in the layout description. Coordinates are not scaled and no additional loop is appended to achieve that distance. The eastern inner hairpin, longer southwestern alternate loop, full southern extension and access spur are excluded. This is historical draft course geometry, not proof of a 939 m timed lap or the current event layout.

The primary [experience operator](https://www.supercarexperience.co.uk/track/northern-ireland/nutts-corner/) identifies the seven-corner car layout at 11 Dundrod Road. The [regional motorsport association](https://www.motorsportni.org/sprint/) independently identifies this sprint venue. These references support venue and course identification; no image coordinates are used. The separate Moira Road stock-car venue is not substituted.

The private shared timing point is within 0.6 m of the selected route. It remains a local preview overlay and is not included in the public download.

The included `historical-main-course-review.png` is a plot of the independently selected source coordinates. Attribution: © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright). Travel direction, lap distance and event-specific alignment need review.
