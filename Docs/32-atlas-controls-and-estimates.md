# Atlas controls and optional width estimates

Four known uncertain cases are excluded from automatic line calculation: Albert Park, Prodrive, Road Atlanta Short and the Road Atlanta combo. They retain their mapped trace and timing data but no scalar road-width data or saved inner/outer/ideal coordinates. Their line controls are visible and disabled, with the reason shown. The current configured width count is 1,182. No new audited boundary corrections or imagery work is included in this follow-up.

For a layout with a mapped centreline and no usable generated boundaries, Track tools offers **Road width (m)** and **Calculate lines**. A user-entered value between 3 and 45 m creates estimated edges and an ideal line in the existing worker. This override exists only in the current page session and never changes public track data or GeoJSON downloads. Reset returns to the dataset's unavailable/default state. Explicit user estimates do not validate uncertain source boundaries. A failed calculation preserves the source trace and leaves the line controls disabled.

While either the boundary or ideal overlay is enabled, the viewer shows: “These lines use estimated track boundaries. Boundary errors can affect line placement and simulated lap results.” The note stays visible when Track tools is collapsed and hides when both overlays are off.

Map/Satellite switches retain the Leaflet zoom and centre. Reset view and selecting a new track still fit its extent; recalculating a manual width retains the current view. Surprise me and Explore world map clear the track-name search before choosing/showing tracks. Country and saved-track filters remain applicable.

Explore world map displays a point for each geolocated catalogue entry. All currently mapped tracks have locations; entries without a location have no mapped trace. At zoom 11 and closer, source outlines are loaded for nearby visible tracks, with three concurrent requests and a forty-track viewport limit. Outlines use a venue's mapped default layout, or its first mapped layout when that default has no coordinates. Clicking a point or outline opens the full track controls. Other layouts remain selectable in the normal layout menu. Source outlines are cached for the page session and hidden outside the current viewport/overview. Leaving the overview cancels pending overview requests. The world view does not start ideal-line workers or fetch the entire geometry database.

Focused checks cover disabled controls and an explicit manual override/reset, unchanged downloads, conditional disclaimer visibility, retained basemap zoom/position, search-independent discovery, progressive outline loading and selection, all geolocated points, and phone overflow. External image/tile requests are blocked during these browser checks; no screenshots or fresh satellite data are used. TypeScript, ESLint, eight focused unit tests and three deployed-preview browser tests pass. Only the persistent Tailscale preview is updated; production publication remains separate.
