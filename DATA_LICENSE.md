# Database license and attribution

The public track catalogue and OSM-derived trace data are made available under the Open Database License 1.0 (ODbL). See the [ODbL text](https://opendatacommons.org/licenses/odbl/1-0/) and the [OpenStreetMap copyright and attribution page](https://www.openstreetmap.org/copyright).

Credit OpenStreetMap contributors when using the database. The source snapshots and each venue's `review.md` identify the OSM material used to generate its traces. The OSM-derived data remain separate from the MIT-licensed application code in [LICENSE](LICENSE).

Authoring inputs and processing procedures are maintained separately from the public application and database.

## Optional track borders

Some layout GeoJSON files include `inner` and `outer` features. They are separate supplemental data, not OSM-derived route coordinates. Legacy supplemental features use the feature-level `license` value `LicenseRef-Track-Borders`. This identifier denotes a separate rights scope: this repository makes no additional redistribution or commercial-use license grant for those legacy features. Obtain suitable permission before reusing them beyond the rights you already hold.

When borders are present, `metadata.licenseScope` is `trace-and-timing`: the collection's ODbL declaration and OSM attribution apply to its original trace and applicable timing data, not to the supplemental border features. Legacy supplemental borders have no borrowed OSM source IDs. Estimated imagery-derived borders instead carry their imagery source ID, the source-specific feature licence (for example public-domain NAIP or Etalab-2.0 IGN imagery), and `borderStatus: estimated`. Their `metadata.borderInference` records attribution, reuse evidence, raster hashes, georeferencing and image-evidence metrics. These estimates are unreviewed; source pixel size and edge evidence do not certify positional accuracy. Application code remains MIT. Neither a display option nor inclusion in a GeoJSON download changes the rights attached to a feature.

Licensed MapTiler-derived estimates use `LicenseRef-MapTiler-Derived-Borders`. The dataset operator has confirmed a separate agreement allowing automated extraction and redistribution of derived coordinates. Agreement text is held separately and was not independently reviewed here. This reference does not relicense the imagery as open data or give recipients additional imagery rights. Attribution and feature-level rights remain attached to each estimate. No satellite raster bytes, API credentials or agreement documents are distributed in the dataset.

A trace independently digitized under that agreement uses the same licence reference in `metadata.license`, with its imagery attribution and registered source ID. It is not declared OSM-derived or relicensed as ODbL. Its pinned source recipe stores georeferencing, raster hash and pixel vertices; the raster stays outside the repository. Only layouts without timing data currently use this source type. `metadata.licenseScope: trace-and-timing` still excludes supplemental borders and terrain from the trace declaration. Check the trace's own declaration before reuse.

## Terrain grids

Approximate ground-elevation grids are stored in `metadata.model3d.terrain` inside prepared layout GeoJSON files, or in `data/elevation/` for other layouts. These are a separate rights scope derived from [Mapzen Terrain Tiles](https://registry.opendata.aws/terrain-tiles/). It retains the underlying terrain providers' rights and attribution requirements; the application does not relicense those inputs as ODbL or MIT. Each embedded grid or venue file includes source credits. The [provider's attribution and license details](https://github.com/tilezen/joerd/blob/master/docs/attribution.md) identify USGS and NOAA global datasets, Copernicus EU-DEM and regional sources from Australia, Austria, Canada, Mexico, New Zealand, Norway and the United Kingdom, plus ArcticDEM.

The public manifest records the original tile URLs and SHA-256 hashes. Modification consists of Terrarium RGB decoding, bilinear sampling onto geographic venue grids and rounding to integer metres. Runtime interpolation and labelled vertical exaggeration affect the display. Neither changes the independently sourced public track coordinates or GeoJSON downloads. The viewer credits terrain beside the model and gives regional credits under Track notes & sources → Elevation data.

Composed networks use `LicenseRef-Component-Borders` on their two multi-path border features. This marker points to `metadata.borderComposition`: each entry retains the original component's border properties, licence, attribution and imagery evidence for the corresponding path index. It grants no additional rights and does not combine those component licences into ODbL. Each reconstructed driving route restores its original feature-level rights. The network shares a terrain grid and stores numeric playback recipes, without meshes or raster imagery.
